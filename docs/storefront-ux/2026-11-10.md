## Research and references (reviewed this run)

- [Christianbook Bible Store](https://www.christianbook.com/page/bibles/) — offers translation-based navigation (ESV, NIV, NLT, KJV, etc.) alongside purpose-based Bible discovery, with guides explaining translations/types. **Application:** translation and reading purpose should be first-class discovery dimensions, not decorative category cards.
- [Crossway ESV Large Print Compact Bible](https://www.crossway.org/bibles/esv-large-print-compact-bible-red-letter-cow/) — product details include type size, page layout, dimensions, format and page count. **Application:** surface comparable edition attributes in listings and details; avoid assuming all ESV editions have the same physical attributes.
- [Crossway ESV Pocket Bible](https://www.crossway.org/bibles/esv-pocket-bible-tru-2/) — 6-point type and compact dimensions make readability-versus-portability a meaningful trade-off. **Application:** explain text size and portability to users comparing editions.
- [Baymard Product List & Filtering UX](https://baymard.com/research-articles/current-state-product-list-and-filtering) — highlights essential filters and visibility of applied filters. **Application:** include explicit applied-filter overview and clear-all affordance.
- [Baymard Filter List Design](https://baymard.com/research-articles/have-filters-for-list-item-info) — displayed product attributes should be available as corresponding filters. **Application:** align visible translation, purpose, and format labels with filtering controls.

These are observed patterns and research recommendations, not evidence that the current store has those products or capabilities.

## UX problem prioritized

The initial Figma file did not yet show how a shopper can narrow Bible choices by translation, reading purpose or print format. For Bible shopping, the same translation can appear in many editions with materially different reading characteristics. A clear filter overview reduces the effort of comparing irrelevant editions.

## Actual editable Figma changes

1. Created a **1440px desktop catalog exploration** with breadcrumb, title, introductory copy, left filter rail (translation, reading purpose, cover/binding, text size, price), sorting affordance, and a 2-column sample product grid.
2. Created a **390px mobile catalog exploration** with separate Filters and Sort controls, an applied-filter summary, clear-all affordance and scannable single-column product rows.
3. Used documented `BIBLE STORE` naming and blue/white/neutral styling instead of introducing another unapproved brand.
4. Marked products, photography and prices as **illustrative/unverified**. Product examples are design placeholders, not claimed inventory.

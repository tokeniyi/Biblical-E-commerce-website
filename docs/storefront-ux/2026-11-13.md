## Research and references

- [Christianbook — Bible catalog filters](https://www.christianbook.com/apps/easyfind?N=1018567+4294862828+4294967135): translation, binding, format, and features are genuine retailer facet dimensions. **This does not validate this project's own inventory.**

## Problem prioritized

The three November 12 static states lack an explicit state-transition contract. Without a clear distinction between draft drawer selections and applied URL facets, implementation could unexpectedly change results before confirmation or lose selections on back navigation.

## Actual editable Figma changes

Created `Catalog · Mobile · Filter interaction contract · 13 Nov 2026` at node `23:2`, 1120 × 1040, containing three annotated mobile state columns: list with applied chips, draft filter drawer, and empty-results recovery. The board specifies Apply → update URL and reset page → E16 loading → results or E02; Cancel discards draft; browser Back restores prior URL state and chips. It uses Inter, neutral surfaces, blue #2563EB, and clearly marked illustrative results. It is a **static interaction specification**, not a working prototype.
